## 💼 Featured Projects

### 1. 🏛️ CivicLens — Civic Management System

A C# and SQL-based civic management system demonstrating real-world Object-Oriented Programming (OOP) concepts. The project focuses on organizing civic information and implementing application workflows through a structured desktop application.

**Technologies:** C#, Windows Forms, SQL Server

[View Repository](https://github.com/firojkoraishisourov/CivicLens)

### 2. 🏨 Hotel Management System

My **first university project**, developed using Java. This project introduced me to practical software development and helped me apply fundamental Object-Oriented Programming concepts to hotel management workflows.

**Technologies:** Java, Object-Oriented Programming

[View Repository](https://github.com/firojkoraishisourov/Hotel_Management_System-java-project-)

### 3. 🇧🇩 Animation of Mega Projects in Bangladesh

A C++ Computer Graphics project featuring animated visualizations of five major infrastructure projects in Bangladesh. The project uses OpenGL and GLUT to bring infrastructure concepts to life through graphical scenes and animation.

**Technologies:** C++, OpenGL, GLUT, Computer Graphics

[View Repository](https://github.com/firojkoraishisourov/Animation-of-Mega-Projects-in-Bangladesh)

### 4. 🛒 TechVault — Online Computer Shop

A full-stack e-commerce web application for browsing, purchasing, and managing computer components and peripherals. Built with plain PHP and MySQL, TechVault provides a storefront experience with role-based access for customers and administrators without relying on a heavyweight framework.

This was a **group project for my Web Technologies course**, where I contributed to the development of the application alongside my teammates.

**Technologies:** PHP, MySQL, HTML, CSS, JavaScript

[View Group Project Repository](https://github.com/Shahjalal-Dip/Online_Computer_Shop)
